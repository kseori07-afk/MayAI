요청

에이전트가 보낸 요청만 표시합니다. 허용·차단 조치는 이후 요청에 적용할 정책으로 저장됩니다.

응답

서버 응답은 기본 허용입니다.
응답 정책에 매칭되면 모니터링 모드에서는 기록만 하고, 차단 모드에서는 응답을 막습니다.

응답 정책

인증된 요청자, 실제 목적지, 응답 탐지 항목으로 매칭합니다.
조건이 더 구체적인 정책이 먼저 적용되고, 완전히 동률일 때만 차단(DENY)이 이깁니다.
정책이 없으면 응답은 허용됩니다.

모니터링 = 차단 정책에 매칭돼도 기록만 · 차단 = 실제로 응답 차단

HTTP(S) 목적지를 호스트:포트 또는 URL로 지정할 수 있습니다. 비워 두면 모든 목적지에 적용됩니다.

에이전트

에이전트 등록과 인증 정보를 관리합니다. 신뢰 상태 관리에서 신뢰 상태와 격리·해제 조치를 볼 수 있습니다.

등록이 삭제된 에이전트의 신뢰 기록

요청 정책

모든 요청에 적용됩니다.
명시적 차단(DENY)이 항상 허용(ALLOW)보다 먼저 적용되고, 그다음은 가장 구체적인 정책입니다.

HTTP(S) 목적지는 IP:포트와 URL 중 한 곳만 입력하세요. URL은 경로와 쿼리까지 비교합니다. 비워 두면 모든 목적지에 적용됩니다.

MAC 보안 등급

STDIO에서 도구·리소스·프롬프트에 적용됩니다. 에이전트 허가 등급보다 높은 대상에 접근하거나, 세션이 보유한 데이터보다 낮은 대상으로 쓰기·전송하면 차단됩니다.

객체 등급 지정

MCP 서버와 대상 유형을 고르고 이름 또는 URI를 입력하세요. query_* 같은 패턴은 선택한 유형 안에서 적용됩니다. 기존 규칙은 목록에 ‘모든 유형’으로 표시됩니다. 등급을 지정하지 않은 대상은 L4 핵심기밀로 취급합니다.

세션별 보유 데이터 등급

한 에이전트 실행에서 사용하는 STDIO 서버들은 세션을 공유합니다. 보유 데이터 등급은 받은 데이터에 따라 올라가며, 새 세션은 이전 세션의 등급을 이어받습니다. 관리자는 필요할 때 L1로 초기화할 수 있습니다.
